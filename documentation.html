Overview

QuickStore is a lightweight, zero-dependency command line tool designed to synchronize local configuration files with remote storage buckets.

Installation

Install the package globally via your preferred package manager:

npm install -g quickstore-cli

Basic Usage

Run the initialization wizard to configure your credentials:

quickstore init --profile=default

To run a sync job:

quickstore sync ./config.json --remote=s3://my-bucket

Configuration Options

Flag Type Default Description
--profile String "default" The local authentication profile to use.
--dry-run Boolean false Simulates the upload without committing changes.
--verbose Boolean false Prints detailed file transfer logs.
